# VTriangles (HW3D)

Лабораторная работа по C++: эффективный поиск пересечений плоских треугольников
в трёхмерном пространстве с визуализацией на OpenGL.

## Исходное задание

Ниже дословно приведена формулировка из [`IDEA.md`](IDEA.md).

Данный проект является лабораторной работой на курсе по C++ для 2го курса бакалавриата от Константина Игоревича Владимирова.

В данной работе нужно реализовать эффективный поиск пересечений плоских треугольников в трёхмерном пространстве.

На вход программа получает до миллиона треугольников. Полный перебор всех пар имеет сложность O(N²), поэтому необходимо использовать пространственное разбиение или другой алгоритм со сложностью порядка O(N) или O(N log N).

Результат необходимо визуализировать с помощью OpenGL:

показать треугольники внутри кубического объёма; подсветить красным все треугольники, участвующие в пересечениях; добавить освещение; реализовать перемещение камеры по сцене.

Алгоритмы пересечения и пространственного поиска необходимо покрыть unit-тестами, включая граничные и вырожденные случаи.

## Текущая реализация

Программа на C++20 читает треугольники из стандартного ввода, один раз вычисляет
признаки пересечения, строит вершины с нормалями и открывает интерактивное окно
с освещённой сценой. Точка входа `src/main.cpp` содержит только чтение данных,
вызовы поиска и запуск приложения.

- чтение произвольного числа треугольников из `stdin`;
- broad phase на основе sweep-and-prune по одной координатной оси;
- предварительная проверка пересечения AABB по всем трём осям;
- точная проверка двух невырожденных треугольников методом разделяющих осей (SAT);
- обработка копланарных треугольников и касаний с фиксированным допуском `1e-5`;
- расчёт сглаженных нормалей для граней с точно совпадающими координатами общей
  вершины и углом до 45 градусов;
- визуализация в OpenGL 3.3 Core Profile;
- подсветка пересекающихся треугольников противоположным RGB-цветом;
- точечный источник света с ambient, diffuse и specular составляющими;
- свободная камера и меню Dear ImGui для настройки сцены;
- опциональная сборка с AddressSanitizer и UndefinedBehaviorSanitizer.

## Текущее состояние

Поиск пересечений выполняется при запуске. Массив `intersects` передаётся в
`BuildTriangleVertices`: каждая вершина содержит позицию (3 float), нормаль
(3 float) и признак пересечения (1 float), всего 7 float. Флаг одинаков для
трёх вершин треугольника и передаётся во фрагментный шейдер без интерполяции.
Обычные треугольники используют выбранный в ImGui базовый RGB-цвет, а
пересекающиеся — противоположный: `vec3(1.0) - material.diffuse`.
При изменении базового цвета подсветка меняется сразу, без обновления VBO.

Выбранный в меню цвет треугольников задаёт `material.diffuse`, а его
`material.specular` остаётся белым. Цвет света применяется и к кубику источника,
и к освещению треугольников (ambient, diffuse и specular).
Параметры освещения, положение и мощность источника, скорость камеры и вращение
света работают.

Вырожденные треугольники, у которых площадь близка к нулю, функция пересечения
считает непересекающимися. Добавлен только проектный регрессионный тест упаковки
признака пересечения, включая проверку несовпадения размеров маски и треугольников.
Полный набор unit-тестов геометрии и пространственного поиска ещё отсутствует;
каталог `external/glm/test/` относится к сторонней зависимости GLM.

## Алгоритм поиска

Для каждого треугольника строится AABB. Ось сортировки выбирается по наибольшему
разбросу центров ограничивающих коробок. После сортировки программа перебирает
только пары, чьи интервалы перекрываются вдоль выбранной оси, затем проверяет
остальные координаты и запускает SAT.

Сортировка требует `O(N log N)`. Число проверяемых пар зависит от сцены; в худшем
случае, когда интервалы большинства объектов перекрываются, поиск остаётся
квадратичным.

Как только оба треугольника уже помечены как пересекающиеся, дальнейшая точная
проверка этой пары пропускается. Реализация хранит только признак участия
треугольника хотя бы в одном пересечении, а не полный список пар.

## Формат входных данных

Первая строка содержит неотрицательное количество треугольников `N`. Затем для
каждого треугольника передаются координаты трёх вершин:

```text
N
x1 y1 z1  x2 y2 z2  x3 y3 z3
...
```

Пробелы и переносы строк равнозначны, поэтому вершины можно записывать в любом
удобном виде.

Пример:

```text
2
0 0 0    1 0 0    0 1 0
0.25 0.25 -1    0.25 0.25 1    1 1 0
```

При ошибке чтения программа выбрасывает `std::runtime_error`. Результаты поиска
в консоль не выводятся: после обработки входа запускается графическое окно.

## Зависимости

Для сборки нужны:

- CMake 3.20 или новее;
- компилятор с поддержкой C++20;
- OpenGL;
- GLFW 3.3 или новее, установленный в системе.

GLM, Dear ImGui и stb_image подключены как git submodules; они перечислены
в `.gitmodules`. GLAD лежит в `external/glad` обычными файлами. После клонирования
инициализируйте подмодули:

```bash
git submodule update --init --recursive
```

## Сборка

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
```

Сборка с санитайзерами для совместимого GCC- или Clang-подобного компилятора:

```bash
cmake -S . -B build-san -DENABLE_SANITIZER=ON -DCMAKE_BUILD_TYPE=Debug
cmake --build build-san --parallel
```

Проект использует относительные пути к моделям, шейдерам и шрифту. Запускайте
исполняемый файл из корня репозитория:

```bash
./build/main < input.txt
```

Регрессионный тест упаковки признака подключён через CTest без дополнительных
тестовых зависимостей (`BUILD_TESTING` по умолчанию включён):

```bash
cmake -S . -B build-test -DBUILD_TESTING=ON
cmake --build build-test --parallel
ctest --test-dir build-test --output-on-failure
```

Для production-сборки без тестовой цели используйте `-DBUILD_TESTING=OFF`.

## Управление

| Действие | Клавиша или устройство |
| --- | --- |
| Движение вперёд, назад и в стороны | `W`, `S`, `A`, `D` |
| Обзор | мышь |
| Изменение угла обзора | колёсико мыши |
| Подъём в режиме полёта | `Space` |
| Спуск в режиме полёта | `Left Shift` |
| Переключение режима полёта и гравитации | двойное нажатие `Space` |
| Перенести источник света в позицию камеры | `L` |
| Открыть или закрыть меню | `Esc` |

В режиме гравитации камера ускоряется вниз. Столкновение с полом и прыжок
в текущем коде не реализованы.
